# Kindness Club — Anti-Bullying English Learning Website

A colourful, responsive, multi-page educational website about bullying, its forms, effects, prevention and support.

## Included pages
- `index.html` — home page, key facts, learning chapters and kindness activity
- `pages/what-is-bullying.html` — definition and key signs
- `pages/types.html` — verbal, social, physical and cyberbullying
- `pages/effects.html` — emotional, physical, social and school effects
- `pages/solutions.html` — practical action plan
- `pages/get-help.html` — asking a trusted person for support
- `pages/quiz.html` — interactive five-question quiz with score and restart

## Run the website
1. Extract the ZIP archive.
2. Open `index.html` in Chrome, Edge or Firefox.
3. An internet connection is recommended for Google Fonts. The website's content, design, navigation, quiz and built-in translations work locally without a translation API.

## Translation mode
- Translation mode starts **ON** on every page.
- Click an English word to show its Georgian meaning and the full containing sentence with its Georgian translation.
- Select a phrase or sentence to translate the selected text.
- Use the **Translation ON / OFF** button to pause or resume translation mode.
- Normal clicks on links continue to navigate between pages. On desktop, **Alt + click** a link to translate its text instead of opening it.
- The project includes exact Georgian translations for the static page text, headings, quiz questions, quiz answers, feedback, and kindness activity suggestions. New or unlisted text uses a clearly marked approximate dictionary fallback.

## Edit the project
- `css/style.css` — colours, layout, responsive design and visual effects
- `js/app.js` — translator dictionary, sentence translations, quiz and kindness activity
